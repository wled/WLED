# Controlling Wiz lights

Enables controlling [WiZ](https://www.wizconnected.com/en/consumer/) lights that are part of the same network as the WLED controller.

Development of this usermod now happens in a [separate repository]([url](https://github.com/eibanez/wled-usermod-wizlights)). Please refer to that repository and the official documentation on [community usermods]([url](https://kno.wled.ge/advanced/community-usermods/#index)) for additional information.
